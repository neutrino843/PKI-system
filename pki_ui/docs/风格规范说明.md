# PKI系统前端UI - 治愈系手绘风格规范说明

## 1. 设计理念

本系统前端采用 **治愈系手绘风（Kawaii Hand-drawn Style）** 设计语言，旨在通过温暖、亲切的视觉质感，降低CA证书管理系统的专业距离感，同时保持功能的完整性和可用性。

## 2. 色彩体系

## 4. 核心组件规范

### 4.1 手绘卡片 (`.hand-card`)
- **边框**: 2.5px 实色边框 (`var(--color-border)`)
- **圆角**: 14-20px（大卡片用20px，小卡片用14px）
- **阴影**: 5px 6px 0，不透明阴影（模仿手绘投影）
- **悬停**: 上移1px + 阴影加大，模拟纸张抬起的物理感

### 4.2 手绘按钮 (`.hand-btn`)
- **结构**: 2.5px 边框 + 圆角14px + 不透明阴影
- **交互反馈**:
  - hover: translate(-2px, -2px) 上移效果
  - active: translate(1px, 1px) 按下效果
  - click: 涟漪波纹动画 (`.ripple`)
- **尺寸变体**: sm (小) / 默认 / lg (大)

### 4.3 手绘输入框 (`.hand-input`)
- **常态**: 2.5px 边框 + 微弱阴影
- **聚焦态**: 边框变色 + 发光外圈 + 轻微上移
- **占位符**: 斜体 + 低透明度

### 4.4 功能磁贴 (`.func-tile`)
- **布局**: flex列，图标在上文字在下
- **交互**: hover 旋转-1deg + 上移 + 阴影加大
- **颜色变体**: 5种底色（粉/绿/紫/橙/蓝）

### 4.5 撕边纸张菜单 (`.side-menu`)
- **右侧边缘**: 使用伪元素 radial-gradient 模拟不规则撕边效果
- **展开动画**: cubic-bezier(0.34, 1.56, 0.64, 1) 弹性缓出
- **背景遮罩**: 半透明 + backdrop-filter 模糊

### 4.6 房子返回按钮 (`.home-btn`)
- **造型**: 圆角胶囊 + 房子SVG图标
- **阴影**: 手绘风格不透明阴影
- **交互**: hover 上移 + 旋转-2deg + 图标放大

## 5. 响应式断点

| 断点 | 目标设备 | 关键变化 |
|:-----|:---------|:---------|
| ≥1024px | 桌面 | 4列磁贴网格，完整导航 |
| 768-1023px | 平板 | 2-3列磁贴网格 |
| 480-767px | 大屏手机 | 2列磁贴网格，顶部导航压缩 |
| <480px | 小屏手机 | 1-2列，卡片内边距缩小 |

## 6. 动效规范

| 元素 | 动效 | 时长 | 缓动函数 |
|:-----|:------|:-----|:---------|
| 页面切换 | fadeIn + translateY | 0.4s | ease-out |
| 按钮点击 | 涟漪波纹 | 0.6s | ease-out |
| 按钮悬停 | 上移 + 阴影变大 | 0.3s | cubic-bezier(0.34,1.56,0.64,1) |
| 菜单展开 | slideIn | 0.4s | cubic-bezier(0.34,1.56,0.64,1) |
| 模态框 | scaleIn | 0.4s | cubic-bezier(0.34,1.56,0.64,1) |
| Toast提示 | slideIn右侧 | 0.4s | ease-out |
| 卡片悬停 | 上移 + 阴影 | 0.3s | ease |
| 磁贴悬停 | 旋转 + 上移 | 0.5s | cubic-bezier(0.34,1.56,0.64,1) |

## 8. 开发还原注意事项

1. **字体加载**: 依赖Google Fonts CDN，需确保网络可访问 fonts.googleapis.com
2. **SVG图标**: 所有图标均为内联SVG，无需额外图标库
3. **CSS变量**: 所有颜色、圆角、阴影使用CSS自定义属性，便于全局修改
4. **移动端适配**: 使用 `max-width` + `grid` 实现响应式，无需额外框架
5. **浏览器兼容**: 支持 Chrome 80+ / Firefox 75+ / Safari 13+ / Edge 80+
6. **离线使用**: 如需离线部署，需下载字体文件到 assets/fonts/ 目录
